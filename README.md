# 蜘蛛侠 · 3D 自由之城

在浏览器里探索 3D 城市，使用双手蛛丝摆荡、跳跃、攀墙，并随时挑战犀牛人、电光人和绿魔。

## 操作

- 手机：左摇杆移动，滑动画面转动镜头。按住左手或右手蛛丝挂住楼顶，松手飞出去。跳跃和攻击使用右侧按钮。
- 电脑：W / A / S / D 移动，拖动鼠标转镜头，空格跳跃，Q / E 分别发射两只手的蛛丝，F 发射攻击蛛丝，Esc 暂停。方向键也可转动镜头。
- 靠近墙壁按住跳跃可以攀墙。城市地图可直接前往 Boss 所在楼顶。
- 击败三个 Boss 后仍能自由探索。地图里可再次挑战已击败的 Boss。

## 用 GitHub Pages 部署

这是一个纯静态网站，不需要安装依赖或运行构建。

1. 在 GitHub 创建一个公开仓库，例如 `spider-free-city-3d`。
2. 将解压后的文件上传到仓库根目录。不要只上传 ZIP 文件，也不要把文件套在另一层文件夹里。
3. 仓库中应直接包含 `index.html`、`style.css`、`game3d.js`、`engine3d.js`、`world3d.js` 和 `favicon.svg`。保留 `.nojekyll` 文件。
4. 打开仓库的 **Settings → Pages**。
5. **Source** 选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存。
6. 等待部署成功，GitHub Pages 设置页会显示可以打开的游戏地址。

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 本地运行

在解压目录中运行：

```sh
python3 -m http.server 8000
```

然后在浏览器中打开 `http://localhost:8000`。由于使用 JavaScript 模块，应通过 HTTP 服务运行，而不是双击 HTML 文件。

## 文件说明

- `engine3d.js`：WebGL 3D 渲染、网格、相机矩阵。
- `world3d.js`：城市生成、角色物理、蛛丝约束、碰撞和 Boss 战斗。
- `game3d.js`：手机与电脑操作、镜头跟随、界面和地图。
- `style.css`：适配手机和电脑的界面。

## 攀墙、逛店与掩体战斗

- 贴近建筑或墙面，按住 C / 攀墙按钮；前后输入控制上爬与下爬，左右移动沿墙横移。爬到楼顶后自动翻上去，松开按钮会脱离墙面。空格 / 跳跃贴墙也可攀爬。
- 城市有三座低层店铺：星环便利店、织光服装店、轨道面馆。可通过城市地图到店门口，按 R / 逛店进入真实 3D 店内空间。
- 店内可以走动，与店员互动补给、收集纪念品或试穿三套战衣。换装保留到离店后；走到门口或点离开店铺返回街区。
- 所有攻击使用运动线段检测墙体与目标，先碰到墙的弹丸会停止并产生撞击效果。自动瞄准和 Boss 攻击也检查视线遮挡，躲在建筑后面可以获得掩护。店内暂停外面的 Boss 战斗。

验证：攀墙与翻上楼顶、松手落下、三店进出、换装保持、补给与逛店记录、高速双方弹丸被墙阻挡、可见目标命中，以及原有移动 / 蛛丝 / Boss 回归。


## 自由探索版：三位蜘蛛侠

选择彼得（平衡）、格温（空中特技加分）、迈尔斯（电能蛛网）。这是原创实现的非官方网页小游戏，玩法方向参考《漫威蜘蛛侠》，并没有使用商业游戏的代码或模型。

- 冲刺 Shift、弹射 Z、拉拽 G、蛛网 X、空中特技 T、闪避 V、轻击 J、重击 K；手机可点蛛丝技能菜单。
- 特技连做获得风格分，120 / 300 分在服装店解锁力量和星耀战衣。力量战衣可以拉动汽车，极光战衣冲刺恢复更快，夜行战衣降低敌人警觉。
- 近身轻重连招、空中连击、范围束缚、环境投掷与完美闪避慢动作。城市事件包括屋顶救援、抢劫、消防救援与无人机追捕；敌人包括打手、狙击手、重甲与飞行单位。
- 寻找五个背包阅读城市故事，城市任务菜单提供线索、事件传送、楼顶休息和摆荡计时；计时记录保存在当前浏览器。
- 外观与设置中切换角色、战衣主色、蛛丝色、面罩、难度、挂点辅助及按键；支持昼夜循环、晴 / 雨 / 雾天气。
- 拍照模式可以暂停、转动镜头、调距离、选滤镜、下载不含操作界面的 PNG，并记录地标打卡。
- 店内贴墙攀到天花板后可倒挂爬行。

当前为单人版本；多人合作和在线排行榜尚未实现。此版本的物理、战斗与店内交互通过自动化检查，实际手机性能及触摸体验需要设备试玩。

## 自由沙盒与小镇更新（2026-10-02）

设置菜单提供蛛丝移动、城市环境、事件与战斗、角色外观、画面与 UI、挑战、控制七个标签。选项即时生效并在当前浏览器保存。纯观光预设关闭敌人、事件与 Boss，固定晴朗夜晚并隐藏 HUD；右上角始终保留设置入口。手机隐藏 HUD 时仍可使用原摇杆与按钮所在的触摸区域，恢复 HUD 可以看见操作按钮。

- **B / 蛛丝捆缚**：独立发射捆缚蛛丝。命中普通敌人困住 6 秒，重甲 2.8 秒，Boss 1.8 秒；迈尔斯额外延长 1 秒。捆住时不能移动或发起攻击，墙壁可以拦截蛛丝。没有弹药数量或消耗限制。
- 54 位普通市民在街区散步，靠近按互动可以交谈。咖啡座争执、迷路游客与购物袋事件可选择帮助，也可直接离开。
- 城市手记中可以选择屋顶蹲下观景、蛛丝倒挂、45 秒特技评分挑战。移动或点起身恢复探索；倒挂会回到该屋顶。
- 街区增加柔和配色矮楼、阳台花箱、遮阳棚、广场喷泉与铁塔。河岸汉堡店、服装店、便利店有对应的立体图案招牌。
- 控制标签可调整镜头灵敏度、反转 Y 轴、自定义全部操作键；Esc 用来取消改键或返回游戏。该键保留用于退出。
- 背景音乐、环境风声、动作音的音量可独立调整到 0；使用原创合成声音，首次点击或按键后启动。
- 破坏效果是碰撞和墙面命中的碎片粒子，建筑主体仍然完整。多人、联机排行榜尚未实现。

检查覆盖设置对真实物理、伤害、刷新、天气、战衣、挑战、角色捆缚与墙体遮挡的影响，及屋顶休息/倒挂稳定性。实际手机触摸手感仍需设备试玩。

## 花园小镇与性能更新

活动边界扩大到 ±800，67 家不重名商店、18 类业态，服装店仅一家。小吃街（z=-275）与美食街（z=165）有专门店铺，地图提供快捷入口；新增喷泉、花园、湖景休息区。店铺以杯子、书本、花朵等立体招牌区分，菜单对应不同品类。格温使用前面开口的白色兜帽、粉色内衬、黑白战衣和青色鞋子。

市民 AI 只计算附近角色，每秒更新五次；最多绘制附近18位普通行人。WebGL 城市按街区分块，只绘制附近网格；无 WebGL 的绘图模式限制模型生成频率，并省略远处过小的细节。角色变换减少临时数组和向量分配。换装更改配色不会增加人物模型数量。

Node 同机检查：240 次物理更新从约10.8秒降到约0.15秒；60次人物生成从约1.07秒降到约0.50秒。它们是代码路径耗时，不能等同于手机帧率，真实手机表现仍需设备试玩。
